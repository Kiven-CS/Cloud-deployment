What is the Azure Developer CLI?

The Azure Developer CLI (azd) accelerates the journey from local development to Azure. Its commands map to key stages in your workflow, whether you work in a terminal, an editor, or continuous integration.

This template completed the following tasks

  1. Packaged the Python app for deployment
  2. Created an Azure Container Registry
  3. Created an Azure Container Apps environment and app
  4. Created Blob and Table Storage resources
  5. Created and assigned a managed identity
  6. Configured identity-based access to Storage
  7. Deployed the app to Azure Container Apps
  8. The app is ready to use
